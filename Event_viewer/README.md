# Explication du fichier DNS_View.xml

Cette vue permet un filtrage de tous les niveaux des évènements DNS.

## Configuration
### Niveaux surveillés
- Critique (1)
- Erreur (2)
- Avertissement (3)
- Information (4)

### Sources d'événements
- **Microsoft-Windows-DNS-Server-Service** : Événements du serveur DNS
- **Microsoft-Windows-DNS-Client** : Événements client DNS
- **Microsoft-Windows-DNS-Client-DiagTrack** : Diagnostics DNS
